# Carlisle Shealy Interiors — GitHub Pages starter site

This is a simple static website you can host for free with GitHub Pages.

## Files
- `index.html` → Home
- `projects.html` → Projects
- `services.html` → Services
- `contact.html` → Contact
- `about.html` → About
- `assets/styles.css` → site styling
- `assets/main.js` → active nav highlighting

## Quick setup
1. Create a new GitHub repository named `carlisle-shealy-interiors`.
2. Upload all files from this folder to the repository.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Save. GitHub will publish the site and give you a URL.

## Optional custom domain
If you later buy a domain like `carlisleshealyinteriors.com`, add it in:
**Settings → Pages → Custom domain**

## Easy edits
- Replace placeholder text in the HTML files.
- Swap the placeholder background images in `assets/styles.css` with your own image URLs or local files.
- Update email, phone, Instagram, and location in `contact.html` and `about.html`.
